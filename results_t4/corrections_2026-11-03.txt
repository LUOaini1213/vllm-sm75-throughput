一、被更正的原话
================================================================
t4_gemm_control.txt 第 24-25 行（2026-09-02）：

  两卡同为 sm_75、同为 Turing，控制变量唯有 Tensor Core 的有无，M=1→2 比值相差约 20 倍。
  「缺少 Tensor Core 导致 cuBLAS fp16 GEMM 小 M 路径病态」的归因成立。

README 第一屏 2026-11-03 之前也写着「唯一差别是 T4 保留了 Tensor Core」「控制变量唯有 Tensor Core 的有无 —— 归因成立」。

================================================================
二、两次运行实际不同的地方
================================================================
                 GTX 1650（无 TC）                    Tesla T4（有 TC）
  torch          2.13.0+cu130                         2.11.0+cu128
  CUDA           13.0                                 12.8
  驱动           592.82                               580.82.07
  系统           Windows 11 + WSL2 Ubuntu 24.04.4     Google Colab（Linux）
  SM 数          14                                   40
  显存           4 GiB                                15360 MiB

出处：
- T4 一列：本目录 t4_gemm_control.txt 第 1 行（40 SM、torch 2.11.0+cu128）；
  CUDA / 驱动 / Colab 来自作者在 pytorch/pytorch#195716 里贴的 Versions 段。
- GTX 1650 一列：同一 issue 的 Versions 段；2026-09-18 在同一台机器上的运行记录
  streaming_accounting_20260918/evidence/local_20260918T054433Z/manifest.json
  里也是 torch 2.13.0+cu130、驱动 592.82、WSL2（那是另一轮实验，只用来佐证软件栈）。
- SM 数：GTX 1650 的 14 SM 是该型号规格；本仓没有 GTX 1650 侧的 gemm_cliff.py 原始输出
  （见 results_local/README.md「这半边还缺什么」）。

所以 2026-09-02 的对照同时改变了 Tensor Core 有无、torch/cuBLAS 版本、驱动、系统和 SM 数。
cuBLAS 13.0 在纯 SIMT 的 Turing 上换了启发式，同样能产出这张表。

三、仍然站得住的部分
================================================================
- T4 一侧的数字（106.7 / 88.1 GiB/s、0.83× / 0.85× / 0.86×）有原始文件，check_claims.py 逐个回算。
- 「缺 Tensor Core 时 cuBLAS fp16 小 M 走了慢路径」仍是最可能的解释：fp32 在同一张 GTX 1650 上
  没有塌陷，T4 上 fp16 也没有。但这是「最可能的解释」，不是「受控对照已确认」。

================================================================
四、要把它变成受控对照，还差一次重跑（需要 GPU，本次没做）
================================================================
1. Colab T4 上 pip install torch==2.13.0 --index-url https://download.pytorch.org/whl/cu130，
   跑 python gemm_cliff.py，原样存成 results_t4/t4_gemm_torch2.13_cu130.txt。
2. 能用到 GTX 1650 的话，反过来装 torch 2.11.0+cu128 再跑一次，原始输出存进 results_local/。
3. 版本对齐后 T4 仍无塌陷、GTX 1650 仍塌陷，才能写「受控对照确认」。
在这之前，README 只写「主要解释」，并列出上面这张版本差异表。
